О проекте

Что такое Шакализатор

Бот с инструментарием для работы с Telegram: профиль, зеркала, партнёрка, промокоды и восемь методов сноса.

Добро пожаловать

Шакализатор SH-V2 работает через сеть сессий: жалобы отправляются от лица множества аккаунтов, что повышает шансы на рассмотрение модерацией. Все методы требуют активной подписки.

Внутри бота — профиль со статистикой, зеркала на случай блокировки основного, партнёрская программа и промокоды на бонусные дни.

Шакализатор не даёт 100% гарантии удаления контента. Решение всегда принимает модерация Telegram. Бот лишь отправляет жалобы в большом объёме.
Функционал

Методы сноса

Восемь инструментов внутри бота. Все требуют подписки.

Bot Snos

Массовые жалобы на ботов. Причина: правила, спам, наркотики. Можно добавить свой текст.

Pyro Snos

Аналог Bot Snos через Pyrogram. Для случаев, где Telethon не справляется.

Channel Snos

Жалобы на каналы. Категории: спам, 18+, насилие, персональные данные.

Message Snos

Жалоба на сообщение по ссылке t.me/username/123 с выбором причины.

Spam Code

Флуд кодами подтверждения через официальные API и OAuth-сервисы. Есть кнопка остановки.

Username Snos

Жалобы на профиль. Имитация «Мой аккаунт взломали» через «Другое → Прочее».

Web Report

Массовые жалобы через telegram.org/support. До 20 жалоб с рандомных почт.

Session Snos

Снос сессий: подключение по номеру, флуд кодами, веб-жалобы, мониторинг.
